# AI-Based Student Dropout Prediction System

## Overview

This project predicts students who are at risk of dropping out using Machine Learning and provides intervention recommendations for counselors.

## Features

* Student Management
* AI Risk Prediction
* Risk Classification
* Risk Factor Analysis
* Recommended Interventions
* Intervention Tracking
* Outcome Tracking
* Analytics Dashboard
* MySQL Database Integration

## Technologies Used

* Python
* Flask
* MySQL
* Pandas
* Scikit-Learn
* Bootstrap

## Dataset

Student Performance Dataset from Kaggle

## How to Run

1. Clone the repository
2. Create virtual environment
3. Install requirements

```bash
pip install -r requirements.txt
```

4. Configure `.env`
5. Run

```bash
python app.py
```

6. Open

```text
http://127.0.0.1:5000
```
